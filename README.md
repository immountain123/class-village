# 클래스 빌리지

초등 학급 운영 도트 마을 웹앱. GitHub Pages에서 화면을, Supabase에서 데이터를 맡아요.

- `index.html`: 웹앱 전체 (학생 마을 + 교사 이장실)
- `supabase/schema.sql`: 데이터베이스 표와 서버 함수. Supabase SQL Editor에서 실행해요.
